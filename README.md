## Featured Project

### DIYplanner — Full-Stack Project Planning App

DIYplanner is a full-stack application for organizing home improvement and DIY projects. It was built with **Java 21, Spring Boot, PostgreSQL, JWT authentication, React, Vite, Docker Compose, and GitHub Actions CI**.

The application supports project tracking, task management, materials tracking, shopping lists, reminders, profile updates, and password workflows.

**Engineering highlights:**

- Layered Spring Boot backend using controller, service, repository, DTO, mapper, and exception-handling layers
- JWT-based authentication integrated with Spring Security
- PostgreSQL persistence for local development with H2-backed automated tests
- React/Vite frontend with reusable components, service modules, and context-based auth/toast state
- Docker Compose setup for local PostgreSQL development
- GitHub Actions CI for backend test validation and frontend build verification
- Clean portfolio repository with environment examples, screenshots, setup instructions, and organized documentation
